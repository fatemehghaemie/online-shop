# Online Shop

A Java-based Online Shop project developed as part of a Software Design course.

## Description

This project implements an online shopping system using Java and Object-Oriented Programming principles.

## Technologies

- Java
- Maven
- Object-Oriented Programming
- Git and GitHub

## Project Structure

```text
online-shop/
├── .gitignore
├── pom.xml
├── src/
│   ├── main/
│   │   ├── java/
│   │   └── resources/
│   └── test/
│       └── java/
└── target/
```

## Run the Project

Make sure Java and Maven are installed.

Run the tests:

```bash
mvn clean test
```
