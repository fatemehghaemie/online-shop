# فروشگاه آنلاین

یک پروژه‌ی فروشگاه آنلاین مبتنی بر Java که به‌عنوان پروژه‌ی درس طراحی نرم‌افزار پیاده‌سازی شده است. برنامه از طریق منوی خط فرمان اجرا می‌شود و قابلیت‌هایی برای مشتریان و مدیر فروشگاه دارد.

## معرفی پروژه

در این پروژه کاربران می‌توانند محصولات را مشاهده و جست‌وجو کنند، حساب کاربری بسازند و سفارش ثبت کنند. مدیر فروشگاه نیز می‌تواند محصولات، موجودی انبار و سفارش‌ها را مدیریت کند. معماری برنامه به بخش‌های مدل، سرویس و رابط کاربری کنسولی تقسیم شده است.

## قابلیت‌ها

### کاربران و حساب کاربری
- ثبت‌نام، ورود و خروج از حساب
- بازیابی رمز عبور با ایمیل یا شماره تلفن ثبت‌شده
- مشاهده و ویرایش اطلاعات پروفایل
- افزودن، ویرایش و حذف نشانی‌های کاربر
- پشتیبانی از نقش مشتری و مدیر

### محصولات و کاتالوگ
- مشاهده‌ی محصولات و جزئیات آن‌ها
- جست‌وجو و مرور محصولات بر اساس دسته‌بندی
- فیلتر و مرتب‌سازی محصولات
- مشاهده‌ی امتیازها و دیدگاه‌های محصولات
- ثبت دیدگاه برای محصولات

### سبد خرید و سفارش
- افزودن محصول به سبد خرید
- تغییر تعداد یا حذف محصولات از سبد
- محاسبه‌ی مبلغ کل سبد خرید
- ثبت سفارش با انتخاب نشانی تحویل
- مشاهده‌ی تاریخچه و وضعیت سفارش‌ها

### قابلیت‌های مدیر
- ایجاد، ویرایش و غیرفعال‌کردن محصولات
- مدیریت دسته‌بندی‌ها و موجودی انبار
- مشاهده‌ی همه‌ی سفارش‌ها یا فیلتر آن‌ها بر اساس وضعیت

### پرداخت
- شبیه‌سازی فرایند پرداخت
- ثبت وضعیت پرداخت موفق یا ناموفق
- بررسی وضعیت پرداخت

> پرداخت در این نسخه شبیه‌سازی شده و به درگاه بانکی واقعی متصل نیست.

## فناوری‌ها و ابزارها

- **Java 17** برای پیاده‌سازی برنامه
- **Apache Maven** برای مدیریت ساخت و اجرای پروژه
- **JUnit Jupiter 5** برای تست‌های واحد
- **Git** برای کنترل نسخه

این پروژه از دیتابیس یا فریم‌ورک رابط کاربری استفاده نمی‌کند. داده‌ها در مخازن درون‌حافظه‌ای نگهداری می‌شوند؛ بنابراین با بستن و اجرای دوباره‌ی برنامه، اطلاعات به حالت اولیه برمی‌گردند.

## ساختار پروژه

```text
online-shop/
├── pom.xml
└── src/
    ├── main/java/org/example/
    │   ├── Main.java
    │   ├── cli/       # منوها و ورودی/خروجی کنسول
    │   ├── model/     # مدل‌ها و مفاهیم اصلی فروشگاه
    │   └── service/   # منطق کسب‌وکار و مخازن داده
    └── test/java/org/example/
        ├── model/     # تست مدل‌ها
        └── service/   # تست سرویس‌ها و جریان‌های فروشگاه




## پیش‌نیازها

- Java Development Kit نسخه‌ی 17 یا بالاتر
- Apache Maven

برای بررسی نسخه‌های نصب‌شده:

```bash
java -version
mvn -version
```

## اجرا

از پوشه‌ی اصلی پروژه، دستورات زیر را اجرا کنید:

```bash
mvn clean compile
java -cp target/classes org.example.Main
```

## اجرای تست‌ها

```bash
mvn test
```

تست‌ها با JUnit Jupiter نوشته شده‌اند و مدل‌ها، سرویس‌ها، سبد خرید، احراز هویت و جریان ثبت سفارش را پوشش می‌دهند.

## اطلاعات ورود مدیر نمونه

با اجرای برنامه، اطلاعات مدیر نمونه در کنسول نمایش داده می‌شود. اطلاعات فعلی نسخه‌ی نمونه:

```text
Email: admin@shop.com
Password: Admin1234
```

این اطلاعات برای اجرای محلی و آزمایشی پروژه هستند.

## محدودیت‌های نسخه‌ی فعلی

- برنامه رابط گرافیکی یا وب ندارد و از طریق کنسول استفاده می‌شود.
- اطلاعات کاربران، محصولات و سفارش‌ها در حافظه نگهداری می‌شوند.
- پرداخت به درگاه واقعی بانکی متصل نیست.
- بازیابی رمز عبور در این نسخه بدون ارسال کد تأیید انجام می‌شود.
